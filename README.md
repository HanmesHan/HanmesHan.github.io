# GitHub Personal Website

This is an English personal website inspired by [Academic Pages](https://github.com/academicpages/academicpages.github.io), ready to deploy with GitHub Pages.

## Deployment

1. Create a public GitHub repository named `your-github-username.github.io`.
2. Upload every file in this directory, or commit and push them from your computer.
3. In the repository, open **Settings → Pages** and choose **GitHub Actions** under **Build and deployment**.
4. When the workflow finishes, visit `https://your-github-username.github.io`.

## First customization

First, replace the name, GitHub username, email, organization, and social links in `_config.yml`. Then replace `assets/images/profile-placeholder.svg` with your own photo. Page content lives in `index.md` and `_pages/`.

Put your CV PDF at `files/cv.pdf` to enable the download button.
